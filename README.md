# Anime Landing Page

## 📖 Overview
A responsive and highly interactive anime landing page designed to showcase popular anime titles, complete with video trailers and detailed character profiles. The interface features a sleek, dark-themed design with glassmorphism elements and smooth CSS animations.

## ✨ Features
*   **Dynamic Anime Slider:** A visually appealing carousel displaying anime titles like *Naruto*, *Attack on Titan*, *Demon Slayer*, *Jujutsu Kaisen*, *Chainsaw Man*, and *Rent a Girlfriend*.
*   **Video Trailer Popups:** Integrated video player modals allowing users to watch trailers for each featured anime without leaving the page.
*   **Character Showcases:** An interactive character panel for each anime, featuring character details, traits, abilities, and a dedicated thumbnail navigation slider.
*   **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices using CSS media queries.
*   **Modern UI/UX:** Utilizes blurred backgrounds, glassmorphism containers, and smooth transitions for a premium feel.

## 🛠️ Technologies Used
*   **HTML5:** Page structure and media integration.
*   **CSS3:** Styling, animations, flexbox layouts, and responsive media queries.
*   **Vanilla JavaScript:** Logic for the slider navigation, trailer popups, character panels, and timeout events.

## 📁 File Structure
*   `index.html`: The main structural document containing the navigation, search bar, and anime list framework.
*   `style.css` & `style2.css`: The primary stylesheets handling the layout, typography, animations, and responsive breakpoints.
*   `script.js`: The JavaScript file managing DOM elements, click events, and slider functionalities.
*   **Media Folders:** Expects local directories for `img`, `bg-img`, `video`, `chr-bg`, and `char-img` to populate the visual assets.
